## App Details
- App name: Contract Whist Score Tracker
- Short description (max 80 chars): Track Contract Whist scores with custom rounds, dealer rotation, and history.
- Full description (max 4000 chars):

Contract Whist Score Tracker helps you run complete games at the table with fewer mistakes and faster scoring.

Features:
- Full and Half game modes
- Custom start/end card counts (deck-size validation built in)
- Dealer rotation and first-bidder guidance each round
- Sequential bid and trick entry with validation rules
- Trump selection (including No Trumps)
- Special rounds: Blind, No Trumps, Miz
- Zero-bid streak rule enforcement
- Live leaderboard and round-by-round breakdown
- Local history of recent games

Designed for casual and competitive Contract Whist groups who want accurate, consistent scoring.

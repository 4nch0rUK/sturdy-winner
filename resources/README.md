# Branding Resources

Generated production source assets for Capacitor:
- `icon.png` (1024x1024)
- `icon-background.png` (1024x1024)
- `icon-foreground.png` (1024x1024 transparent)
- `splash.png` (2732x2732)

Regenerate at any time:

```powershell
npm run brand:assets:win
```

Then create native platform icon/splash sets:

```powershell
npm run cap:assets
```

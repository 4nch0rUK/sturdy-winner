# Contract Whist Score Tracker

Web app for scoring Contract Whist with custom round flow, special rounds, and history tracking.

## Local Run
Open `index.html` in a browser.

## Publish and App Builds
See [PUBLISHING.md](PUBLISHING.md) for:
- web deployment via GitHub Pages
- Android/iOS packaging with Capacitor
- Android CI artifact builds on tags

## Branding + Store Assets
- Generated app icon/splash source assets are in `resources/`.
- Store listing templates are in `store-listing/`.
